# FinSight AI – Financial Controller Agent

**An AI-powered Financial Controller Assistant for Finance and Business Management.**

## Project Overview

FinSight AI is a prototype AI Financial Controller designed to support financial managers and business leaders through structured financial analysis, budget monitoring, and cash flow assessment.

The project combines an AI Agent with dedicated calculation tools to improve the reliability and clarity of financial management insights.

## Key Features

### 1. Budget vs. Actual Analysis
- Calculate actual and budget operating profit.
- Measure revenue and expense variances.
- Calculate operating profit margins.
- Identify favorable and unfavorable performance variances.

### 2. Cash Flow & Liquidity Analysis
- Calculate net cash flow.
- Determine closing cash balance.
- Compare available cash against minimum cash requirements.
- Identify liquidity surplus or shortfall.

### 3. AI-Powered Management Insights
- Interpret financial calculation results.
- Explain financial risks.
- Provide practical management recommendations.
- Present structured financial reports.

## Technology Stack

- n8n – Workflow Automation
- OpenAI GPT-5 mini – AI Language Model
- JavaScript – Financial Calculation Tools
- AI Agents and Tool Integration

## Architecture

User Input → Chat Trigger → AI Agent

The AI Agent connects to:
- OpenAI Chat Model
- Budget vs. Actual Calculation Tool
- Cash Flow & Liquidity Calculation Tool

Deterministic calculations are handled by dedicated JavaScript tools, while the AI Agent interprets the results and generates management insights.

## Testing

The prototype has been tested using synthetic financial data.

Validated calculations include:
- Actual and budget operating profit
- Revenue and expense variances
- Operating profit margins
- Net cash flow
- Closing cash balance
- Liquidity surplus and shortfall
